# 矿寻 V0.1 开发范围

为中国矿业大学学生和失物委员提供本机浏览器演示。提供学生和委员两个演示身份，数据与上传图片保存在当前浏览器。真实账户、跨设备同步、AI 服务及部署留待后续版本。

| 功能区 | 验收范围 |
| --- | --- |
| 首页与广场 | 双发布入口、最新信息、自然语言搜索、关键词搜索、寻物和招领列表、分类／地点／时间组合筛选、清除及无结果状态。 |
| 信息发布 | 选择寻物或招领，批量选取并移除图片，填写物品名称、类别、地点、时间和描述，核对 AI 示例建议，预览后确认发布。新记录出现在广场和个人中心。 |
| 物品详情 | 图片、物品字段、发布者和角色标识，演示留言、申请认领与查看匹配。 |
| 个人中心 | 我的发布、消息、认领记录及认领结果。发布者可以处理申请。 |
| 委员工作台 | 委员身份切换、批量收件、待整理队列、AI 模拟整理建议、整理并填入发布表单、协助发布、复制转发文案。 |

AI 交互使用本地示例。搜索展示语句中的物品、地点与时间条件，图片识别和委员整理提供可编辑建议，匹配根据类别、地点和时间展示反向类型的候选。识图建议按演示文件名产生，未知名称会给出待确认提示。验收包括 PC 和移动端的核心流程，以及刷新后的数据保留。
