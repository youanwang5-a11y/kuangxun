# 矿寻设计规范

使用「矿寻」与「中国矿业大学」作为产品和学校名称。白色卡片搭配暖白页面底色 `#F7F9F7`，正文深松绿 `#16342D`，主操作 `#087C66`，浅薄荷 `#E4F3EA` 表示招领或 AI 提示，浅杏 `#FFF0E2` 表示寻物。状态同时用文字表达。

桌面导航包括首页、失物广场、个人中心和发布入口。桌面使用多列卡片、双栏发布表单和个人中心侧栏。移动端改为单列列表、堆叠表单和「首页／广场／发布／我的」底部导航。使用实际可聚焦控件、清晰表单标签和可见焦点。重要反馈放在对应操作旁。

用 CSS 自定义属性集中维护主题。首页使用独立校园插图，物品照片以方形裁切复用于列表、详情和待办。发布确认、模拟留言、认领和转发使用带标题、关闭操作和键盘支持的对话框。AI 功能在浅薄荷色提示区标明模拟状态，预览后由用户确认保存。
