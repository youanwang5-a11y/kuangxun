# 矿寻

面向中国矿业大学学生的校园失物招领网站。学生可以查找、发布和认领物品，失物委员可以整理待办并协助发布。

V0.1 计划采用原生 HTML、CSS、JavaScript 和 Node.js，在本机提供浏览器演示。运行入口计划为 `npm start`，检查入口计划为 `npm run check`。当前阶段已确认设计和开发范围，应用入口将在实现阶段加入。
