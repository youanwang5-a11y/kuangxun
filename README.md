# 矿寻

面向中国矿业大学学生的校园失物招领网站。V0.1 基础框架版包含首页、失物招领广场、发布页、物品详情、个人中心和失物委员工作台，支持 PC 和移动端。

## 启动与检查

安装 Node.js 20 或更新版本，在项目根目录运行以下命令。项目使用原生 HTML、CSS、JavaScript 模块和 Node.js，无需安装额外依赖。

```shell
npm start
npm run check
```

用 `npm start` 启动后，打开 [本地站点](http://127.0.0.1:4173/)。检查命令在另一个终端运行，执行语法检查和 Node 内置测试。Windows PowerShell 若限制脚本执行，可使用 `npm.cmd`。

## 体验流程

- 首页点击「试试示例」，体验规则模拟的 AI 搜索，然后到广场按关键词、类型、类别、地点和时间筛选。
- 发布寻物或招领信息，批量选图、调整 AI 示例建议，预览并确认。新记录出现在广场与「我的发布」。
- 在招领详情提交认领或留言。进入个人中心切换为失物委员，即可体验收件、整理建议、协助发布、转发和处理收到的认领申请。

AI 搜索、图片建议、匹配和委员整理均标为模拟。发布、图片、消息、认领和待办使用 IndexedDB 保存在当前浏览器的站点数据中。V0.1 的账号和留言用于本机演示，真实认证、即时聊天、服务端共享、AI API 和上线部署留待后续迭代。
